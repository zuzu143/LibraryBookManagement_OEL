# OEL final submission checklist

- [ ] Replace the student/group information on the PDF cover with both real names and registration numbers (group size must be exactly TWO).
- [ ] Run the application yourself in an IDE using an installed JDK; demonstrate Add, View, Update, Delete and status changes.
- [ ] Demonstrate an invalid empty title and a duplicate ID (observe error messages).
- [ ] Run `scripts/test.sh` or `scripts\\test.bat`; compare output with evidence/test-results.txt.
- [ ] Open `docs/javadoc/index.html` in a browser and identify one class and its methods.
- [ ] Demonstrate `git status`, `git log --oneline --graph`, `git diff HEAD~1 HEAD`.
- [ ] Create a GitHub repository, add the remote and push, verify the code online; put actual URL in your report or on the cover.
- [ ] PDF report uploaded to Google Classroom (GCR).
- [ ] Project ZIP uploaded to Google Classroom (GCR).
- [ ] Print full PDF report; two members attend individual viva.
- [ ] Confirm whether late submission is permitted: handout says GCR closes 22 November and viva begins 23 November.

*The package's screenshots, source tests, generated HTML docs and local Git history are genuine artifacts created in the preparation environment. Your own IDE run, GitHub push and classroom submission remain student actions.*
